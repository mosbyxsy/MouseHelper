# MouseHelper — 鼠标增强工具


> 基于**AutoHotkey v2**的鼠标增强工具：
>
> 长按右键即可把滚轮变成方向键 / 横向滚动（也支持无需右键的全局模式），把侧键变成复制 / 粘贴，并提供误触保护与双击快捷切换，让普通鼠标拥有更多快捷能力。



* **脚本文件**：`MouseHelper.ahk`

* **运行环境**：Windows + AutoHotkey v2.0 或更高版本

* **退出方式**：按 `Ctrl+Alt+Q`，或右键托盘图标 → Exit



***

## 1. 功能总览



| 功能   | 触发方式           | 效果                       |
| ---- | -------------- | ------------------------ |
| 功能 1 | 长按【右键】+ 滚动滚轮 / 滚动滚轮；长按【右键】+ 单机【左键】切换 | 滚轮变为 ←/→ 方向键，或横向滚动（4 种模式循环） |
| 功能 2 | 长按【右键】+ 鼠标侧键；双击【右键】切换 | 后侧键 = 复制，前侧键 = 粘贴（切到复制粘贴模式后可免长按【右键】）|
| 功能 3 | 按 `Ctrl+Alt+Q` | 弹出提示后立即退出脚本              |
| 误触保护 | 单击右键 / 右键拖拽    | 普通右键菜单正常保留，拖拽行为不被破坏      |

## 2. 功能详解

### 2.1 功能 1：滚轮实现左右按键 / 横向滚动

滚动滚轮被映射为左右按键/横向滚动操作，共有 **4 种模式**：按住右键的同时点一下左键（即左键 + 右键同时按下），按 1 → 2 → 3 → 4 → 1 → … 循环切换，切换时右下角弹出当前模式提示。

| 顺序 | 模式 | `ScrollMode` 值 | 按住右键时 | 不按右键时 |
| --- | --- | --- | --- | --- |
| 1 | 左右按键（按住右键） | `"keys"` | 滚轮 = ←/→ 左右按键 | 滚轮 = 默认行为（正常滚动） |
| 2 | 横向滚动（按住右键） | `"hscroll"` | 滚轮 = 横向左 / 右滚动 | 滚轮 = 默认行为（正常滚动） |
| 3 | 左右按键（无需右键） | `"keys_always"` | 滚轮 = ←/→ 左右按键 | 滚轮 = ←/→ 左右按键 |
| 4 | 横向滚动（无需右键） | `"hscroll_always"` | 滚轮 = 横向左 / 右滚动 | 滚轮 = 横向左 / 右滚动 |

**按键映射**（`keys` / `keys_always`）：



| 操作     | 效果            |
| ------ | ------------- |
| 滚轮上滚   | 发送 `←`（Left）  |
| 滚轮下滚   | 发送 `→`（Right） |
| 倾斜滚轮向左 | 发送 `←`        |
| 倾斜滚轮向右 | 发送 `→`        |

**横向滚动映射**（`hscroll` / `hscroll_always`）：



| 操作          | 效果                |
| ----------- | ----------------- |
| 滚轮上滚        | 横向左滚 `WheelLeft`  |
| 滚轮下滚        | 横向右滚 `WheelRight` |
| 倾斜滚轮向左 / 向右 | 横向左滚 / 横向右滚       |

**模式 1 / 2（按住右键生效）**：按住鼠标右键不松开，滚动滚轮即被映射为方向操作；松开右键后恢复正常滚动（宽限期 150ms 内仍映射，便于收尾）。

**模式 3 / 4（无需右键，全局生效）**：任何时刻滚动滚轮都会被映射，无需按住右键，适合希望滚轮始终作为方向键 / 横向滚动使用的场景。

**方向提示**：滚动时会在光标右下方用系统 `ToolTip` 显示一个方向箭头（`←` 或 `→`），同一时间只显示一个，滚动停止约 400ms 后自动消失。

> 横向滚动每次的滚动格数由 `HScrollStep` 控制，默认 1 格，可调大加快滚动速度。

### 2.2 功能 2：侧键实现复制 / 粘贴

侧键按键映射（长按右键或复制/粘贴模式下）


| 操作                 | 效果              |
| ------------------ | --------------- |
| 后侧键（XButton1） | 复制（发送 `Ctrl+C`） |
| 前侧键（XButton2） | 粘贴（发送 `Ctrl+V`） |

复制 / 粘贴结果会以 `ToolTip` 形式显示在光标附近（约 2.5 秒后消失）：

* 复制成功：`✓ 已复制`
* 复制失败：`✗ 复制失败，请先选中内容`（剪贴板内容没有变化）
* 粘贴成功：`✓ 已粘贴`
* 剪贴板为空：`✗ 剪贴板为空，请先复制`

> 复制成功与否通过「剪贴板序列号是否变化」来判断，比单纯发快捷键更可靠。

**双击右键切换侧键功能**，可切换「不按右键时」侧键的行为：

| 侧键模式            | 不按右键时侧键的行为                |
| --------------- | ------------------------- |
| 默认模式（`default`） | 保持原始功能（浏览器 / 资源管理器后退、前进等） |
| 复制/粘贴模式（`copy`）  | 后侧键 = 复制，前侧键 = 粘贴         |

切换时右下角弹出当前模式提示，托盘图标文字同步更新。

**双击判定期间消耗右键默认行为**：双击切换时两次点击均不会弹出系统右键菜单；普通单击右键的菜单会延迟约 `DblClickMs`（默认 500ms）补发，若延迟期间发生第二次点击则视为双击、取消补发并切换模式。

> **重要规则：**
>
> * 按住右键时，侧键始终为复制 / 粘贴，不受该切换影响；
> * 双击判定只针对「普通右键点击」（没有移动、没有使用任何功能），拖拽和功能使用后的松手不会误判为双击；
> * 双击切换时两次点击均不弹出系统右键菜单（右键默认行为被消耗）；代价是普通单击右键的菜单会延迟约 `DblClickMs`（默认 500ms）出现。

### 2.3 功能 3：Ctrl+Alt+Q 退出

按 `Ctrl+Alt+Q`，弹出「正在退出脚本」提示后**立即**退出脚本（无需二次确认）。也可以右键托盘图标选择 Exit 退出。

### 2.4 误触逻辑（右键菜单保护）

脚本拦截了右键，因此设计了完整的误触还原逻辑，保证普通右键行为不被破坏：



| 情形                        | 处理方式                                              |
| ------------------------- | ------------------------------------------------- |
| 单纯按下并松开右键（没移动、没用任何功能）     | 视为普通右键点击，延迟 `DblClickMs` 后补发 `{RButton}` 弹出菜单；期间再次单击右键 = 双击切换，不弹菜单 |
| 按住期间使用过功能（滚轮 / 侧键 / 切换模式） | 松开时不弹菜单，并进入**宽限期**（默认 150ms），宽限期内滚轮仍映射 ←/→，便于收尾滚动 |
| 按住期间鼠标移动超过阈值（默认 5px）且没用功能 | 视为**右键拖拽**：自动补发右键按下，松开时补发右键松开，完整还原原生拖拽行为，不弹菜单     |

这样即使误按右键，也能还原成正常的系统右键菜单或拖拽，不会产生「功能被吞」的割裂感。

## 3. 使用方法

### 3.1 安装包使用

- 下载[MouseHelper](https://github.com/mosbyxsy/MouseHelper/releases)到本地；
- 双击`MouseHelper-v1.x.x.exe`运行。

> 注意：
> - 无需安装，直接双击运行；
> - 使用安装包时，不需要安装AutoHotkey。

### 3.2 安装与运行脚本



1. 安装 **AutoHotkey v2**：[https://www.autohotkey.com/](https://www.autohotkey.com/)（安装时选择 v2 版本）；

2. 双击运行 `MouseHelper.ahk`；

3. 托盘出现脚本图标，并弹出右下角提示「鼠标增强工具已启动」即生效；

4. 退出：按 `Ctrl+Alt+Q`，或右键托盘图标选择 Exit。

### 3.3 操作速查表



| 操作                   | 效果                    |
| -------------------- | --------------------- |
| 长按右键 + 滚轮上           | `←`（按键模式）/ 横向左滚（横向模式） |
| 长按右键 + 滚轮下           | `→`（按键模式）/ 横向右滚（横向模式） |
| 长按右键 + 倾斜滚轮左 / 右     | 左 / 右（按键模式 = ←/→，横向模式 = 横向左 / 右） |
| 按住右键 + 点左键           | 切换滚轮模式（4 态循环：按键 → 横向滚动 → 按键全局 → 横向滚动全局） |
| 长按右键 + 后侧键（XButton1） | 复制                    |
| 长按右键 + 前侧键（XButton2） | 粘贴                    |

| 单击右键                 | 正常系统右键菜单（延迟约 500ms 出现） |
| 右键拖拽（按住移动超阈值）        | 正常拖拽                  |
| `Ctrl+Alt+Q`         | 退出脚本                  |

## 4. 配置项

位于脚本「配置区」，按需修改后**重新运行脚本**生效（修改不热更新）。



| 配置项               | 默认值      | 说明                                         |
| ----------------- | -------- | ------------------------------------------ |
| `ScrollMode`      | `"keys"` | 初始滚轮模式：`"keys"`= 左右按键（按住右键）、`"hscroll"`= 横向滚动（按住右键）、`"keys_always"`= 左右按键（无需右键）、`"hscroll_always"`= 横向滚动（无需右键） |
| `DragThreshold`   | `5`      | 右键拖拽判定阈值（像素）：按住右键移动超过该值视为拖拽                |
| `GracePeriodMs`   | `150`    | 使用功能后松开右键的宽限期（毫秒），期内滚轮仍映射 ←/→              |
| `HudOffsetX`      | `16`     | 箭头 / 操作提示相对光标右下角的水平偏移（越大离光标越远）             |
| `HudOffsetY`      | `16`     | 箭头 / 操作提示相对光标右下角的垂直偏移（越大离光标越远）             |
| `HudHideMs`       | `400`    | 滚动停止后方向箭头停留的毫秒数                            |
| `HScrollStep`     | `1`      | 横向滚动模式每次滚动格数（可调大加快）                        |
| `ActionTipHideMs` | `2500`   | 复制 / 粘贴 ToolTip 提示停留的毫秒数                   |
| `DblClickMs`      | `500`    | 右键双击判定间隔（毫秒），500 = Windows 默认双击速度          |

## 5. 实现方式

### 5.1 代码结构



```
MouseHelper.ahk

├─ 头部说明注释（功能、使用方法、备注）

├─ 配置区          # 用户可调的常量（见第 4 节）

├─ 内部状态        # GestureUsed / isDragActive / isGracePeriodActive / SideBtnMode 等

├─ 提示函数

│  ├─ ShowArrow() / HideArrowHUD()      # 方向箭头（ToolTip ID=1）

│  └─ ShowActionTip() / HideActionTip() # 复制/粘贴结果（ToolTip ID=2）

├─ 基础函数

│  ├─ Notify()               # TrayTip 右下角提示

│  ├─ ScrollModeName()       # 当前滚轮模式名称

│  ├─ SideBtnModeName()      # 当前侧键模式名称

│  ├─ ModeTip() / IconTip()  # 托盘图标提示摘要文本

│  ├─ MarkGestureUsed()      # 标记「本次右键已使用功能」并停止拖拽检测

│  ├─ ToggleScrollMode()     # 切换滚轮模式（4 态循环）

│  ├─ ToggleSideBtnMode()    # 切换侧键模式

│  └─ WheelAction(dir)       # 滚轮映射动作

├─ 热键定义（#InputLevel 1 防止自我触发递归）

│  ├─ \*RButton / RButton Up  # 右键按压状态机 + 双击判定

│  ├─ RestoreRClickMenu()    # 延迟补发右键菜单（双击时被取消）

│  ├─ CheckForDrag()         # 10ms 定时拖拽检测

│  ├─ EndGracePeriod()       # 宽限期结束

│  ├─ #HotIf 滚轮 → WheelAction / 左键 → ToggleScrollMode

│  └─ XButton1 / XButton2    # 侧键（复制/粘贴或透传）

├─ CopyAction / PasteAction  # 复制粘贴实现

└─ 退出 & 启动提示
```

### 5.2 关键机制

**（1）**`#InputLevel 1`**&#x20;防止递归**

脚本内部会 `Send` 合成按键（还原右键、补发拖拽、透传侧键等）。将热键输入级别设为 1 后，脚本自身 Send 的事件不会再次触发本脚本的热键，避免形成无限递归。

**（2）**`#HotIf`**&#x20;条件热键**



* 滚轮映射：`keys` / `hscroll`（按住右键模式）仅在 `(按住右键 且 非拖拽) 或 宽限期内` 生效；`keys_always` / `hscroll_always`（无需右键模式）任何时刻均生效 —— 「按住右键模式」下拖拽过程中滚轮保持原生行为；

* 左键切换模式仅在 `按住右键 且 非拖拽` 时生效，不影响普通左键操作。

**（3）右键按压状态机**



* `*RButton`（按下）：重置 `GestureUsed` / `isDragActive` / `isGracePeriodActive`，取消待定的 `RestoreRClickMenu` 定时器（双击时第一击不弹菜单），记录起点坐标，启动 10ms 定时器 `CheckForDrag`；

* `CheckForDrag`：按住期间每 10ms 检查鼠标是否移出阈值；一旦判定为拖拽，立即 `BlockInput` + 把鼠标移回起点 + 补发 `{RButton Down}`，从而「借」出一次原生右键按下供拖拽使用；

* `RButton Up`（松开）：按状态分派 ——


  * 拖拽中 → 补发 `{RButton Up}` 完成拖拽；

  * 使用过功能 → 进入宽限期（150ms），不弹菜单；

  * 普通点击 → 检查是否与上一次普通点击构成双击：是则切换侧键模式（两次点击均不弹菜单），否则延迟 `DblClickMs` 后补发 `{RButton}` 还原右键菜单，并记录本次时间戳（延迟期间再次按下右键会自动取消）。

**（4）双击判定**

双击只对「普通右键点击」计数：用 `lastRClickTime` 记录上次普通点击的松手时间，若两次普通点击间隔 ≤ `DblClickMs`（默认 500ms）即判定为双击。拖拽、使用功能后的松手不更新该时间戳，因此不会误触发。判定为双击时两次点击均不弹系统右键菜单（右键默认行为被消耗）。

**（5）ToolTip 提示体系**



* **方向箭头**：`ToolTip(← 或 →, X, Y, 1)`，ID=1，位置 = 光标 + `HudOffsetX/Y`，`HudHideMs` 后调用 `ToolTip(,,,1)` 隐藏；

* **复制 / 粘贴结果**：`ToolTip(标题·内容, X, Y, 2)`，ID=2，与方向箭头互不干扰、可同时显示，`ActionTipHideMs` 后隐藏。

**（6）复制成功判定**

调用 `GetClipboardSequenceNumber`（user32）取得剪贴板序列号，发送 `Ctrl+C` 后最多轮询 10 次（每次 50ms）等待序列号变化；序列号变了才认为复制成功，否则提示「复制失败」。

**（7）状态变量一览**



| 变量                    | 含义                                        |
| --------------------- | ----------------------------------------- |
| `GestureUsed`         | 本次右键按压是否使用过功能（滚轮 / 侧键 / 切模式）              |
| `isDragActive`        | 本次右键按压是否已判定为拖拽                            |
| `isGracePeriodActive` | 是否处于松开右键后的宽限期                             |
| `startX` / `startY`   | 右键按下时的鼠标位置（拖拽检测基准）                        |
| `SideBtnMode`         | 侧键模式：`"default"`（原始功能）/ `"copy"`（复制 / 粘贴） |
| `lastRClickTime`      | 上次普通右键点击松开的时间戳（双击判定用）                     |

## 6. 注意事项与常见问题



1. **未安装 AutoHotkey**：脚本无法直接运行，需先安装 AutoHotkey v2（[https://www.autohotkey.com/](https://www.autohotkey.com/)）。

2. **个别程序不响应横向滚动**：少数软件不响应注入的 `WheelLeft/WheelRight`，可把 `WheelAction` 里的 `Send` 改为 `SendEvent`（脚本头部备注中已注明）。

3. **侧键默认功能**：不按右键且处于默认模式时，侧键透传为原生事件，浏览器 / 资源管理器中的后退、前进等照常工作；部分游戏内侧键也保持原功能。

4. **双击切换与右键菜单**：双击右键切换侧键模式时，两次点击均不弹出系统右键菜单（右键默认行为被消耗）；作为代价，普通单击右键的菜单会延迟约 `DblClickMs`（默认 500ms）才出现，可调小该值加快响应。

5. **系统双击速度差异**：若双击切换手感不对，可调整配置区 `DblClickMs`（默认 500ms，与 Windows 默认双击速度一致）。

6. **管理员权限程序**：若目标程序以管理员权限运行，普通权限的脚本可能无法向其注入按键，此时需要以管理员身份运行脚本。

7. **修改配置需重启**：配置区参数在脚本启动时读取，修改后需重新运行脚本生效。
